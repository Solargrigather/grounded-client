## 🧩 About

**Grounded Client** is a comprehensive mod menu for Grounded featuring ESP, radar, loot tracker, resource locator, and co-op sync.

Based on popular mods like **Grounded Trainer**, **Grounded Cheat Menu**, and **Grounded ESP**.

---

## ✨ Features

### 🎮 Core Features
- ESP — see creatures, players, and resources through walls
- Radar — minimap overlay showing nearby entities
- Loot Tracker — track items and containers
- Resource Locator — find specific resources easily
- Co-op Sync — share ESP data with teammates

### 🎨 Visuals & Customization
- Custom Colors — adjust ESP colors for each entity type
- Distance Indicators — show distance to targets
- Box ESP — draw boxes around targets
- Name Tags — display names above players and creatures

### 🏋️ Utility & Training
- Teleport — move to waypoints or coordinates
- Speed Boost — increase movement speed
- Infinite Stamina — never run out of stamina
- Instant Build — build structures instantly
